Ramo 구현 기능 리스트

세 구역별 기능을 연관성 있는 묶음으로 정리했습니다. 굵은 항목은 주요 기능입니다.

정리 기준: 사용자가 실제 화면에서 접하는 기능 단위로 묶고, 구현 세부 디테일은 필요한 설명만 포함했습니다.

대화창

대화 시작 및 메시지 작성

  • 랜딩 화면 또는 현재 노드에서 질문을 입력하고 전송할 수 있음
  • Enter 전송, Shift+Enter 줄바꿈, 입력창 자동 높이 조절 지원
  • 전송 직후 사용자 메시지 대기 표시와 답변 생성 중 로딩 표시 제공
  • 첨부 버튼으로 파일 업로드, 이미지 미리보기/문서 칩 표시, 첨부 삭제 지원

모델 선택 및 답변 라벨

  • 대화 입력 영역에서 사용할 모델을 선택할 수 있음
  • 답변 상단에 모델명을 표시함
  • 파트너가 지정된 노드에서는 “모델명 · 파트너명” 형식으로 표시함
  • 파트너가 없는 기본 상태에서는 ramo 같은 기본 페르소나명은 숨김

브랜치 기반 대화 흐름

  • 어시스턴트 답변에서 새 브랜치를 생성해 대화를 분기할 수 있음
  • 현재 세션 이름과 현재 노드까지의 경로를 상단에 표시함
  • 경로 안의 노드를 눌러 다른 노드와 현재 노드를 비교할 수 있음
  • main 경로 여부를 상단 상태로 확인할 수 있음

상위 노드 대화 확인

  • 현재 노드의 가장 위 대화 위치에서만 상위 대화 보기 버튼을 표시함
  • 위쪽 화살표로 상위 노드 대화를 한 노드씩 추가로 펼침
  • 아래쪽 화살표로 펼친 상위 노드 대화를 한 노드씩 닫음
  • 상위/하위 대화 이동 버튼을 눌러도 화면 스크롤이 강제로 이동하지 않음

세션 및 노드 비교

  • 대화창 상단에서 세션 이름을 직접 수정할 수 있음
  • 현재 노드와 선택한 노드의 메시지를 나란히 비교할 수 있음
  • 병합 노드에서는 원본 노드 요약을 별도 패널로 확인할 수 있음

스플릿뷰 대화

  • 브랜치 시각화 창에서 선택한 노드를 별도 대화 패널로 열 수 있음
  • 스플릿뷰 안에서도 메시지 작성, 모델 선택, 파일 첨부, 브랜치 생성이 가능함
  • 현재 대화창/스플릿 대화창/시각화 창의 폭을 조절할 수 있음

모델 답변 비교

  • 두 개 모델을 선택해 같은 질문에 대한 답변을 비교할 수 있음
  • 비교 결과에서 원하는 모델 답변을 선택해 대화 흐름에 반영할 수 있음
  • 두 답변의 차이 분석 패널을 열 수 있음
  • 사용자가 입력한 융합 방식에 따라 두 답변을 합쳐 대화로 보낼 수 있음
  • 모델 비교 창을 최소화했다가 다시 펼칠 수 있음

사이드바

홈 및 새 대화 진입

  • RAMO 홈 버튼으로 시작 화면으로 이동할 수 있음
  • 새 대화 버튼으로 새로운 루트 세션을 시작할 수 있음
  • 현재 선택된 세션이 사이드바 목록에서 강조 표시됨

세션 목록 탐색

  • 루트 세션 목록을 사이드바에서 확인하고 선택할 수 있음
  • 세션 카드에는 제목과 간단한 메타 정보가 표시됨
  • 모바일/좁은 화면에서는 접힘 상태와 콘텐츠 표시 상태를 조절함

세션 관리

  • 세션 우클릭 메뉴에서 세션 이름을 수정할 수 있음
  • 세션을 삭제해 휴지통으로 이동할 수 있음
  • 삭제 시 세션 단위/브랜치 단위가 구분되어 처리됨

휴지통 관리

  • 휴지통 버튼에서 삭제된 항목 개수를 확인할 수 있음
  • 삭제한 세션 또는 브랜치를 휴지통 목록에서 확인할 수 있음
  • 휴지통 항목 복원과 영구 삭제를 지원함
  • 영구 삭제 전 되돌릴 수 없다는 확인 절차를 거침

사용자 프로필 영역

  • 하단 프로필 영역에 사용자 이름 “말랑이”를 표시함
  • 업로드된 프로필 이미지를 현재 UI 크기에 맞춰 보여줌
  • 프로필 영역 옆 다운로드 버튼을 제공함

사이드바 표시 제어

  • 사이드바 접기/펼치기 버튼 제공
  • 접힘 상태에서는 툴팁으로 버튼 의미를 보조함
  • 화면 크기에 따라 사이드바 콘텐츠 노출 방식을 조정함

브랜치 시각화 창

브랜치 그래프 열람

  • 현재 세션의 노드와 노드 관계를 그래프로 표시함
  • 현재 노드, main 경로, 병합 노드, 병합 선택 노드를 서로 다른 스타일로 구분함
  • 노드를 클릭해 해당 브랜치 대화로 이동할 수 있음
  • 간선으로 일반 분기와 병합 흐름을 시각적으로 표현함

그래프 조작

  • 확대/축소 버튼과 마우스 휠 줌을 지원함
  • 그래프를 드래그해 화면 안에서 이동할 수 있음
  • 맵 방향을 세로/가로로 전환할 수 있음
  • 전체화면 그래프 모달을 열 수 있음

스플릿뷰 연동

  • 시각화 창의 “스플릿뷰” 모드를 켜고 노드를 선택할 수 있음
  • 선택한 노드는 우측 스플릿 대화창으로 열림
  • 스플릿뷰 선택 모드에서는 노드 클릭 동작이 대화 이동이 아니라 스플릿 열기로 바뀜

노드 우클릭 메뉴

  • 노드 이름을 수정할 수 있음
  • 선택한 노드를 main 경로로 지정할 수 있음
  • 노드 합치기 기능으로 병합 대상을 선택할 수 있음
  • 하위 노드를 접거나 다시 펼칠 수 있음
  • 노드와 하위 브랜치를 휴지통으로 이동할 수 있음

도움 받을 파트너 지정

  • 우클릭 메뉴에서 “도움 받기”를 눌러 파트너 선택 창을 열 수 있음
  • 파트너 선택 창 제목은 “도움 받을 파트너”로 표시됨
  • 기획 컨설턴트, 번역 전문가, 글쓰기 코치, 학습 멘토, 개발 파트너, 어학 코치를 선택할 수 있음
  • 선택한 파트너는 해당 노드와 동일 브랜치의 하위 노드 전체에 적용됨
  • 이미 파트너가 지정된 노드에서는 같은 위치에 “도움 해제” 버튼을 표시함
  • 도움 해제는 선택한 노드와 하위 노드에만 적용되고 상위 노드 파트너는 유지됨

파트너 시각화

  • 파트너가 지정된 노드는 중앙에 작은 역할 아이콘을 표시함
  • 아이콘 색상은 회색/연녹색 계열로 통일하고 형태로 역할을 구분함
  • 줌 크기가 바뀌어도 같은 브랜치의 아이콘 디자인이 동일하게 보이도록 처리함
  • 노드 hover 설명창에서 노드 이름 옆에 파트너명을 작은 초록색 글씨로 표시함
  • 대화창 답변 라벨에도 선택한 파트너명이 모델명 옆에 표시됨

노드 라벨 및 설명

  • 노드 이름은 10글자를 기준으로 제한함
  • 10글자를 넘는 이름은 가운데 높이에 맞춘 말줄임표로 표시함
  • 노드 hover 시 이름, 파트너, 태그, 설명 정보를 하단 설명창에 표시함

전체화면 및 노드 병합

  • 전체화면 그래프에서 더 넓게 브랜치 구조를 확인할 수 있음
  • 노드 합치기 모드에서는 병합 추천 노드와 추천 이유를 표시함
  • 추천 노드를 바로 선택하거나 직접 다른 노드를 선택할 수 있음
  • 두 노드를 선택한 뒤 합치기를 실행해 병합 브랜치를 생성할 수 있음

파트너 종류

  • 기획 컨설턴트 — 아이디어를 검증하고 구체화해요
  • 번역 전문가 — 의미와 맥락을 살려 자연스럽게 번역해요
  • 글쓰기 코치 — 글의 구조와 표현을 더 명확하게 다듬어요
  • 학습 멘토 — 어려운 개념을 이해할 수 있게 설명해요
  • 개발 파트너 — 구현 방법을 찾고 오류를 함께 해결해요
  • 어학 코치 — 실제 대화를 하며 외국어 회화를 연습해요
